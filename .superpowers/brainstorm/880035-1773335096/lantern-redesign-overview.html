Key Design Decisions

Select which approach resonates with you

A

Tabs Integrated in Header Bar

Like GNOME Prompt / Chrome — tabs sit in the center of the header bar. Saves vertical space. Uses adw::TabBar + adw::TabView for native GNOME tab behavior (drag reorder, overflow, animations).

B

Tabs Below Header (Supacode Style)

Tabs in their own row below the header bar, like in your Supacode screenshot. More room for tab labels. Still uses adw::TabBar but positioned below the header in the content area.

C

Minimal Tabs (Current Plan)

Keep the current manual tab bar (ToggleButtons) but with icons and better styling. Less refactoring, but won't have native tab features like drag reorder or overflow scrolling.

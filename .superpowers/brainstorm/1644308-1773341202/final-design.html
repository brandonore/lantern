Architecture Summary

Header Bar

  • 3 icon buttons left: sidebar toggle, add repo, new tab
  • "Lantern" title center
  • 2 icon buttons right: search, hamburger menu
  • Menu contains: splits, tab ops, remove repo, settings

Sidebar

  • gtk::ListBox with navigation-sidebar CSS class
  • Group headers as uppercase section labels
  • Selected repo highlighted with accent color
  • Git meta (branch, dirty, ahead/behind) per row
  • "+ Add Repository" button at bottom

Tab Bar

  • adw::TabBar + adw::TabView
  • Positioned below header, above terminal
  • Native drag reorder, close buttons, overflow
  • Each tab page contains a VTE terminal (or split layout)

Terminal Area

  • Zero margins — terminal fills all available space
  • VTE terminal with theme-matched colors
  • Split panes via gtk::Paned inside tab pages
  • Subtle status bar at bottom (branch, agent detection)
